# CS-CMS-Attack-detection
Implementaciones de CountMin, CountSketch y CountMedian para la detección de ataques scan y DDoS usando una ventana deslizante sobre una traza.

Para trabajar con este proyecto, se necesita de una distribución de linux, dado que usa varios comandos exclusivos del sistema operativo.

Para usuarios de Windows, se recomienda usar WSL para ejecutar el proyecto. WSL se puede enlazar a Visual Studio Code por medio de la extensión WSL del editor de código. 

También se recomienda crear un entorno virtual de Python para la ejecución de los scripts.
